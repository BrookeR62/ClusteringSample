Cell 4: Feature Scaling with StandardScaler

Code

scaler = StandardScaler() X_train_scaled = scaler.fit_transform(X_train) X_test_scaled = scaler.transform(X_test)

Code Explanation

Line 1: Create StandardScaler Object

Initializes a StandardScaler object that will learn scaling parameters from training data.

Line 3: Fit and Transform Training Data

Formula: z = (x - μ) / σ where μ = mean, σ = standard deviation

  • fit(): Learns the mean and standard deviation for each feature
  • transform(): Applies standardization using learned parameters

Example transformation:

Original sepal_length: [4.3, 5.8, 7.9] (range: 4.3 to 7.9, mean ≈ 5.8) Scaled sepal_length: [-1.5, -0.1, 1.8] (range: -1.5 to 1.8, mean ≈ 0)

Line 4: Transform Test Data Only

Important: Uses transform() only, NOT fit_transform()

Why? Prevents data leakage - test data must be scaled using only information from training data.

Why Feature Scaling Matters for SVM

Aspect Without Scaling With Scaling
Feature Range Sepal: 4.3-7.9, Petal: 0.1-2.5 All: -2 to 2
Distance Calc Large-range features dominate All weighted equally
Model Bias Biased toward high-range features Fair contribution from all
Training Speed Slower Faster & more stable
Prediction Accuracy Lower precision Higher precision
Output:
• X_train_scaled: NumPy array of shape (120, 4) with standardized values
• X_test_scaled: NumPy array of shape (30, 4) with standardized values
